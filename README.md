🧩 8-Puzzle Game — Пятнашки с ИИ-решателем

Классическая головоломка "Пятнашки" (8-puzzle) с визуализацией и интеллектуальным решателем на основе алгоритма A*. 
Приложение находит оптимальное решение и демонстрирует его в пошаговой анимации.

Возможности:

🎮 Игровой процесс:
1) Классическое поле 3×3 с числами от 1 до 8 и пустой клеткой;
2) Плавная анимация перемещения плиток;
3) Современный интерфейс с кастомными стилизованными кнопками.

🧠 ИИ-решатель:
1) Алгоритм A* (A-star) для поиска оптимального пути;
2) Эвристика — Манхэттенское расстояние (сумма расстояний каждой плитки до целевой позиции);
3) Гарантированно находит кратчайшее возможное решение;
4) Проверка разрешимости головоломки (чётность инверсий).

🎯 Управление:
1) Кнопка	Действие;
2) Перемешать	Генерация случайного разрешимого состояния;
3) Решить	Поиск оптимального решения и запуск анимации;
4) Сброс	Очистка решения и остановка анимации;
5) Стоп	Остановка текущей анимации.

📊 Отображение информации:

Текущий шаг анимации / общее количество шагов,
Направление каждого перемещения (Вверх/Вниз/Влево/Вправо).
Полный путь решения в текстовой области.
Статусные сообщения (поиск решения, ошибки, завершение).

Алгоритм A* для 8-puzzle;

Формула оценки:
f(n) = g(n) + h(n)

где:

1) g(n) — стоимость пути от начального состояния до текущего (количество шагов);
2) h(n) — эвристическая оценка оставшегося пути (Манхэттенское расстояние).

Манхэттенское расстояние:
Для каждой плитки вычисляется сумма модулей разностей координат:

h(state) = Σ |current_row - target_row| + |current_col - target_col|
Это допустимая и непротиворечивая эвристика, что гарантирует оптимальность A*.
